## Featured projects

### 🛠 AI Operations Automation Agent &nbsp;·&nbsp; [Code](https://github.com/Giresh-458/ai-operations-agent) &nbsp;·&nbsp; [Live demo](https://ai-operations-agent.streamlit.app)

A stateful LangGraph agent with intent routing, request validation, tool execution, bounded retries and result verification.

- **Corrective RAG (CRAG)** over PostgreSQL — document relevance grading and query rewriting
- **Safety layer** — PII pre-checks, heuristic prompt-injection filters, human-in-the-loop approval gates
- **Observability** — PostgreSQL audit logging across the full lifecycle
- **Tests** — deterministic coverage for tool execution, guardrails and evidence/no-evidence RAG flows

`Python` · `LangGraph` · `FastAPI` · `PostgreSQL` · `Docker`

### 🏥 Healthcare Document Intelligence & RAG Assistant &nbsp;·&nbsp; [Code](https://github.com/Giresh-458/Healthcare-Document-RAG-Assitant) &nbsp;·&nbsp; [Live demo](https://healthrag.streamlit.app)

An OCR-enabled RAG pipeline for PDFs and scanned reports, built to answer only when the evidence supports it.

- **Hybrid retrieval** — BM25 and dense-vector search combined with Reciprocal Rank Fusion (RRF)
- **Adaptive query routing** with bounded retrieval expansion
- **Evidence-sufficiency gate** with fail-closed abstention instead of unsupported answers
- **Grounded output** — structured source citations and PHI/PII redaction

`Python` · `LangChain` · `ChromaDB` · `BM25` · `OCR` · `FastAPI`

### 🔍 Placement Intelligence Agent &nbsp;·&nbsp; [Code](https://github.com/Giresh-458/IIITS-Placements) &nbsp;·&nbsp; *in progress*

A hiring-intelligence pipeline for discovering campus recruitment notices across fragmented institutional sources.

- Bounded crawling over static portals, JavaScript-rendered pages and PDF documents
- Extraction and normalisation of company, role, CTC, branch, graduation batch, CGPA and deadline fields
- Freshness and eligibility-based qualification, with FastAPI and PostgreSQL persistence

`Python` · `FastAPI` · `PostgreSQL` · `Crawlee` · `Playwright` · `Docker`
